    • Import HSN/GST first (master data)
    • Import Categories second (master data)
    • Import Products third (uses both above as foreign keys)
    • Incorrect order will cause validation errors

⚠️  REPLACE MODE FOR PRODUCTS
    • Use "Replace" mode for import_products.csv to clear the old 21 sample
      products and ensure a clean import
    • Use "Merge" mode for master data (HSN/GST, Categories) to preserve
      any customizations

⚠️  IMAGE URLS
    • Images reference application assets (paths like /api/designers/assets/...)
    • These should work in the same deployment environment
    • If images don't load, verify the asset server is running

TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════════════════

❌ "Foreign Key Not Found" error?
   → Make sure to import in correct order (HSN/GST, then Categories, then Products)

❌ Products don't show in the shop?
   → Verify IS_ACTIVE = 'Y' for products
   → Check that public access is enabled for the shop page

❌ Images not displaying?
   → Check that asset paths are correct (should start with /api/designers/assets)
   → Verify asset server is accessible
